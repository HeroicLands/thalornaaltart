# thalornaaltart

## 0.0.2

### Patch Changes

- **Artwork** — The twelve Byzarían character portraits follow their beings to the new shortcodes, so alternative art stays bound to each person.

The site now builds from the generated Hugo configuration on `@heroiclands/package-build@^22.1.1`, which includes organization-wide header links alongside its own.

**A site is its homepage and its pages.** The homepage publishes at `/<package>/` and every note is one page at `/<package>/<type>-<shortcode>/`. Generated section and tag listings are gone; an index between them is a `doc` note the owner writes.

**The module's website page carries the organization's shared header navigation.**

**Foundry listing and site metadata** are now independent. The module's Foundry package browser pitch and the site's meta description are each authored for their own reader — the pitch as HTML, the meta description as plain text — with no contention between them.

- **Artwork** — The two undead pictures follow the beings to their new names, so the tereb and the damut keep their alternative art.
