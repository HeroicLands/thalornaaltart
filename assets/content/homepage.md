Alternative artwork for [Thalorna](/thalorna/), the setting module for the
[Song of Heroic Lands](/sohl/) system.

Thalorna ships artwork drawn for it. This module replaces that artwork with
machine-generated pictures — the same ones the website and the printed
sourcebook carry. Install it and Thalorna's characters, creatures, totems and
faith emblems take on those images instead; disable it and they return to what
Thalorna ships.

It changes nothing else. There is no content here: no beings, no rules, no
journal text. It is pictures, answering to addresses Thalorna already publishes,
which is why it does nothing on its own.

## Installing

This module requires [Thalorna](/thalorna/), which in turn requires the
[Song of Heroic Lands](/sohl/) system.

Install it from Foundry's **Add-on Modules > Install Module** screen, using this
manifest URL:

```text
https://github.com/HeroicLands/thalornaaltart/releases/latest/download/module.json
```

The source lives at
[HeroicLands/thalornaaltart](https://github.com/HeroicLands/thalornaaltart).

## About the artwork

Every picture in this module is machine-generated, and each one says so in the
record that travels with it. That is why it ships apart from Thalorna rather
than inside it: the setting is meant to stand on artwork made for it, and this
is the other option, chosen deliberately by whoever installs it.
